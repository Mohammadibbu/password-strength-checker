# 🔐 Password Strength Checker

A responsive and interactive password strength checker built with **React**. It gives real-time feedback on how strong your password is based on length, character variety, and common patterns.

👉 **Live Demo:** [Check it here](https://mohammadibbu.github.io/password-strength-checker/)

---

## 🛠️ Features

- Real-time password strength feedback
- Visual strength meter
- Validation based on common security rules
- Built with React and deployed via GitHub Pages
